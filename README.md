# E-TİCARET ANALİZ SİSTEMİ

Bu projede bir e-ticaret sitesine ait satış verileri Python ve Pandas kullanılarak analiz edilmiştir. Amaç; farklı veri kaynaklarını birleştirerek satış verileri üzerinden temel analizler yapmaktır.

Projede veri temizleme, veri birleştirme ve satış analizleri gerçekleştirilmiştir.

---

# Kullanılan Teknolojiler

* Python
* Pandas
* NumPy

---

# Veri Setleri

Projede üç farklı veri dosyası kullanılmıştır.

# Projede Yapılan İşlemler

* CSV dosyalarının okunması
* Eksik verilerin temizlenmesi
* Veri setlerinin birleştirilmesi
* Satış tutarının hesaplanması
* Groupby ile satış analizleri
* Apply fonksiyonu kullanımı
* Concat ile yeni veri ekleme
* En çok kazandıran ürün analizi
* En değerli müşterilerin belirlenmesi
* Sonuçların Excel dosyasına aktarılması

---

# Kullanılan Pandas İşlemleri

* DataFrame işlemleri
* Merge
* Concat
* Groupby
* Apply
* Missing Data Cleaning

---

# Çalıştırma

Projeyi çalıştırmak için:

```
python analysis.py
```

Program çalıştırıldığında satış analizleri terminalde görüntülenir ve analiz sonuçları **analysis.xlsx** dosyasına kaydedilir.
